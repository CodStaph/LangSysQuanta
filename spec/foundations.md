## 1. 结论：最小可行数学栈

```text
┌──────────────────────────────────────────────────────────┐
│ 证明层  分离逻辑 / Iris（S5）、Lean 4（T4a 机械化）      │
├──────────────────────────────────────────────────────────┤
│ 判定层  树自动机（RTT / UB-10）、事件结构（hb / Irq）    │
├──────────────────────────────────────────────────────────┤
│ 求解层  Datalog 最小模型（借用/region）、格论（effect）  │
├──────────────────────────────────────────────────────────┤
│ 代数层  半环（cost）、重写系统（comptime / AST patch）   │
└──────────────────────────────────────────────────────────┘
```

自下而上：**越靠下越便宜、越早落地**。全部是离散数学与程序逻辑，
**不含泛函分析、拓扑学、群论**（见 §5）。

## 2. 第一梯队：已在用，只缺显式化

| 工具 | 数学对象 | 现有接点 | 显式化后得到 | 现状 |
|---|---|---|---|---|
| **序 / 格论** | 偏序集、并半格、最小不动点 | `modes.md` 区域格与 mode 格；`effects.md` 的 `∪` / `⊑`；`semantics.md` 的求解器 | 用 Knaster–Tarski / Kleene 不动点替换「树高有限」的手工终止性论证 | 纸面（隐含） |
| **抽象解释** | Galois 连接、抽象域、不动点解 | 最小不可满足核（`00 §4.5`）；`ls cost` 上界；`#[bounds(off)]` | 「最小核」= 抽象域上的最小解释；成本上界 = 抽象解释的解 | 未开始 |
| **半环** | `(max,+)` 热带半环、product semiring | `00 §6.10`、`cost.md` | 成本组合从表格经验值变成代数；多维成本用积半环 | 未开始 |
| **Datalog / 最小模型** | Horn 子句、最小模型、半朴素求值 | 区域约束 `ρ₁ ⊑ ρ₂`；`#[cap]` 传播；增量检查（G-S5） | 求解器从「伪代码 + 并查集」变成声明式规则；PTIME 可判定、增量可维护 | 未开始 |
| **重写系统** | 项重写、固定点、求值策略 | `comptime`、常量折叠、AST patch 重放、`stage2 == stage3` | 确定性构建与自举固定点的正式说法 | 部分（实测） |

**必须写清的三个结构事实**（否则会证出错误定理）：

1. **区域不是完整格**：`Region ::= local(π) | region(R) | thread(d) | heap(H) | static`，
   `⊑` 是树序，`⊔ = LCA`；**没有 bottom**（兄弟 `local` 不可比），**没有 GLB**。
   要套 Knaster–Tarski，需把每个变量的定义域取为**主滤子** `↑local(site(v))`（有限完备格），
   或加一个虚拟 `⊥` 根。
2. **效果是带底的并半格**：`(℘(Eff), ∪, Pure)`，`Pure` 是最小元。
   它**不是**有界格：没有 `⊓`、没有 `⊤`、没有补。文档中的「效果代数」目前是比喻。
3. **mode 是带转换的偏序，不是格**：`freeze` 单向、`recover` 回归、`R1–R8` 是转移规则；
   没有定义 `join` / `meet`。不要写成「mode 格有格运算」。

另：`comptime` 的确定性来自**固定求值序**（`ub.md` UB-12），不是合流性；
只有未来允许多种求值顺序时，才需要 Church–Rosser。

## 5. 明确排除

| 理论 | 唯一「看似接点」 | 为什么不用 |
|---|---|---|
| **泛函分析** | `ls cost` 的「上界」 | 成本是离散半环 `(max,+)`，不是范数 / 内积 / 收敛 |
| **拓扑学** | 偏序 ↔ Alexandrov 拓扑 / 特殊化序 | 只是换名，不增加证明力；本项目无开集 / 连续映射 / 紧致性场景 |
| **群论 / 表示论** | 「正交轴」、对称性 | 文本中的「正交」是线性代数比喻；无群作用 / 置换 / 不变量计算 |
| **测度论 / 概率** | `agent` 的预算 | 当前语言无随机性；`unsafe` 审计是证明义务，不是风险概率 |
| **完整范畴论** | 「三轴 + gate matrix」可被范畴化 | 成本远超团队与工具链现状；先证 T4a 再谈范畴化 |

**术语澄清**（防止被误读成「用了高等数学」）：

- 「生命周期代数」（`00 §0`）—— region 约束求解的通俗说法，不是代数结构；
- 「仿射性 / affine」（`00 §4.3`、`semantics.md`）—— **线性逻辑**的 affine（至多一次），不是仿射空间；
- 「Mmio 仿射性」（`00 §4.3`、ADR-3）—— cap 不可复制 / 不可克隆，与线性代数无关。

## 7. 纪律（F1–F6）

| # | 纪律 | 说明 |
|---|---|---|
| **F1** | **不洗白** | `T4` 仍是「未证明」；引入工具只让它**可证**，不改变 `semantics.md` 状态表中的结论。对外不得写「安全子集无 UB 已成立」。 |
| **F2** | **可执行优先** | 每个工具必须落到 `tools/checker-spike` 的可执行规则，或一条可被审阅的纸面定理；否则移入 §4。 |
| **F3** | **G-S5 预算** | 任何单次求解 > 200ms 的工具不得进入编辑循环；SMT 只用于 `seal` / 认证路径。 |
| **F4** | **片段声明** | 工具只对其声明片段成立（`F0` / `F_thr` / `unsafe` / `agent`）；扩大片段必须新增引理。 |
| **F5** | **反例义务** | 每条工具至少一个负例：不满足该结构时，现有规则会错误接受或错误拒绝什么。 |
| **F6** | **不改 surface** | 本文件不新增语法、诊断码、`H-LS-*` 级别；只改规范的写法与证明路线。 |
