> **上位**：[`semantics.md`](semantics.md) §5.4（T4 拆分）、

> `t4-proof.md` 只引用本文件，不复制定义。

---

## 1. 定义

```text
F0 = 单线程
   ∧ 无 spawn / join / Irq / Dma
   ∧ 无 shared / atom / cell / static
   ∧ 无 unsafe / rawptr / Ffi / Asm
   ∧ 无递归
   ∧ 无 Mmio / Hw
   ∧ 无 comptime
   ∧ 无泛型单态化 / 区域多态 / ref[Trait] 动态分派 / 跨模块调用
   ∧ Trusted = ∅

保留：let / move / read / write、region / alloc / borrow / freeze / recover、
      drop、call / return、Array / Slice、struct / enum / match、定义好的 trap
```

> `F0` 是**语义限制**，不是第二套语法。所有 `F0` 程序都是 `spec/langSysQuanta.ebnf`
> 的子集程序；`F0` 只是从中挑出 T4a 要证明的那一片。

---

## 2. 排除项与归属

| 排除项 | 理由 | 由谁覆盖 |
|---|---|---|
| `spawn` / `join` / `Irq` / `Dma` | 多域交错不在单线程小步语义内 | T4e；`H-LS-3` / `H-LS-16` |
| `shared` / `atom` | 需要原子/锁模型 | T2、T4e |
| `cell` / `static` | 别名边界 / 初始化顺序未收口 | `M-3`、`H-LS-19` |
| `unsafe` / `rawptr` | 深层 soundness 明确降级 | T4b；`H-LS-4` |
| `Ffi` / `Asm` | 跨边界行为无法在语言内核证明 | T4c；`H-LS-5` |
| 递归 | 栈上界需要静态分析 | T4d；`H-LS-29` |
| `Mmio` / `Hw` | 后端 volatile/重排模型 | T4b；`H-LS-6` |
| `comptime` | fuel/能力边界 | `H-LS-17` |
| 泛型单态化 / 区域多态 / `ref[Trait]` / 跨模块 | 各自需要独立引理（ground instantiation、T1a 扩展、vtable ABI、`Trusted` 闭包） | `H-LS-18`、`T1a-mono`、ADR-17、`H-LS-5` / `H-LS-24` |

「F0 之外」**不等于**「不安全」：它表示「不在 T4a 的证明范围」，需要 T4b–T4e 或显式假设。

---

## 3. 与 B-LS 的关系（重要）

**B-LS ⊂ L-Sys，但 B-LS ⊄ F0。**

B-LS 的 `Option[T]` / `Result[T,E]` / `?`、用户泛型 `enum`/`fn` 走单态化 + 装箱，
属于 F0 之外的 E-1。因此：

- `stage2 == stage3` 证明的是**编译链固定点**（`H-LS-8`），不是 T4a；
- 对外写「B-LS 已自举」时，不得同时暗示「F0 已证」；
- B-LS 新增特性不自动扩大 F0；要扩大必须走 §4。

---

## 4. 变更规则

1. **只许缩小**。扩大 `F0` 必须新增一条对应引理（T4b–T4e），并登记 `H-LS-*`。
2. 任何修改必须同时改：本文件 → `feature-coverage.md` → `semantics.md` 的 T4 拆分小节，
   然后跑 `bash tools/check-docs.sh`。
3. 不允许把 `Mmio`/`cell`/`Trusted`/`shared` 静默塞进「安全子集」。
4. 修改理由写进 `results/S1-semantic-freeze.md` 或对应 ADR。

---

## 5. 与 L1 / L2 的关系

- **L1（规范冻结）**的规则与正负例覆盖**全语言**（R1–R8 含 `shared`/`atom`/`spawn`），
  不以 `F0` 为界；
- **L2（定理冻结 / T4a）**只覆盖 `F0`；
- 因此 R6/R8 的语料可以留在 `tests/conformance/pending/`，不影响 T4a 的边界；
  但 L1 的「可执行」要求检查器实现对应规则。
