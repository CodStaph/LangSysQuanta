## 语义

```ls
let s: Slice[U8] = slice(buf, 0, 8);    // slice(arr, off=字节, len=元素)  ← 历史语义
let t: Slice[U8] = slice_at(s, 2, 3);   // slice_at(src, off=元素, len=元素)
```

- `src`：`Slice[T]` 变量（`T` 必须与目标一致）、`Str`（按字节，目标必须是 `Slice[U8]`）、
  或 `Array` 名（等价于 `slice`，`off` 仍按元素缩放）；
- **`off` 以元素计**：`base' = src.base + off * elem`；`len'` 直接取第三个参数；
- 无运行期边界检查（与现有数组/切片一致，越界 = 未定义，见 `spec/bls.md` 的 B-LS 边界）；
- 目标必须是新的 `Slice[...]` 声明（与 `slice()` 同一语法位置，不产生一等 slice 值）。

## 实现

| 位置 | 改动 |
|---|---|
| `bootstrap/seed/seed.c` | 新语句 `S_SLICE_AT` + 解析分支（`Slice[T] = slice_at(src, off, len);`）+ codegen（`shl rax,3` 缩放 `T=Int`，`push/pop` 保存偏移，基址来自 src 的 slice/str 槽） |
| `bootstrap/seed/interp.inc` | `S_SLICE_AT` 的解释执行（同样按元素缩放，`Str` 按字节） |
| `bootstrap/bls/tests/slice_at.ls` | 覆盖 `Slice[U8]` / `Slice[Int]` / `Str` 源、嵌套子视图、`.len`/索引 |
| `bootstrap/ci/run-interp.sh` | 新增 `check .../slice_at.ls 88` |

测试程序返回 88：`(t[0]+t[2])*10 + u[1] + ti[0]/10 + (bs[0]-99) + (bs[1]-99)`
= `(3+5)*10 + 5 + 2 + 0 + 1`。
