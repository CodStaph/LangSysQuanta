# B0.3b 拆解 · 抽 `emit_body`（纯搬家，行为不变）

> 状态：**B0.3b-1 + B0.3b-2 完成（2026-10-22）**。B0.3a（`slice_at`，seed + stage1）已完成并 QEMU 验证；
> 固定点 `b9a21c38…bbb7d`（B0.3b-2 后）。本文把「抽 1,001 行语句循环」拆成可逐步验证的切片。

## 1. 循环的真实依赖（实测）

`main` 内 `while 1 { … }`（约 1,001 行）依赖：

| 类别 | 项 | 数量/用法 |
|---|---|---|
| `Slice[U8]` | `c`(code)、`ds`(data)、`srcs`(source) | 每语句都用 |
| `Slice[Int]` | `ps`(post, 131072)、`st`(16)、`cs`(16) | 高频 |
| 控制/补丁数组 | `ck/cje/cstart/cjmp/bloop/bpos/rname/fname/flabel/fret/fret_t1/fret_t2/fret_ty/fparams/fpelem` | 17 个数组共 1,280 ints（含此前漏计的 `cjmp`） |
| 标量 | `dlen`(87 处)、`cd`(56)、`nf`(32)、`nbrk`(8)、`have_ret`(2) | **必须能跨函数读写** |

参数预算（≤6）：`ctxi(Int)`、`code(U8)`、`data(U8)`、`src(U8)`、`ps(Int)`、`n` = **6**，
所以标量必须放进 `ctxi`。

## 2. 两步走

### B0.3b-1（完成，安全、可独立验证）：把 Int 状态打包成一个 `ctx` 数组 + 视图

`slice_at` 的源必须是 `Slice[T]`/`Str`（B0.3a 语义），所以先给 `ctxa` 建一个覆盖全长的
`ctxi`，再从 `ctxi` 开子视图：

```lean
let ctxa: Array[Int, 2048] = Array.zeroed();
let ctxi: Slice[Int]       = slice(ctxa, 0, 2048);
let st: Slice[Int]         = slice_at(ctxi, 0, 16);
let cs: Slice[Int]         = slice_at(ctxi, 16, 16);
let ck: Slice[Int]         = slice_at(ctxi, 32, 64);
let cje: Slice[Int]        = slice_at(ctxi, 96, 64);
let cstart: Slice[Int]     = slice_at(ctxi, 160, 64);
let bloop: Slice[Int]      = slice_at(ctxi, 224, 64);
let bpos: Slice[Int]       = slice_at(ctxi, 288, 64);
let rname: Slice[Int]      = slice_at(ctxi, 352, 64);
let fname: Slice[Int]      = slice_at(ctxi, 416, 128);
let flabel: Slice[Int]     = slice_at(ctxi, 544, 128);
let fparams: Slice[Int]    = slice_at(ctxi, 672, 16);
let fpelem: Slice[Int]     = slice_at(ctxi, 688, 16);
let fret: Slice[Int]       = slice_at(ctxi, 704, 128);
let fret_t1: Slice[Int]    = slice_at(ctxi, 832, 128);
let fret_t2: Slice[Int]    = slice_at(ctxi, 960, 128);
let fret_ty: Slice[Int]    = slice_at(ctxi, 1088, 128);
let cjmp: Slice[Int]       = slice_at(ctxi, 1221, 64);
// 标量槽：NF=1216, DLEN=1217, CD=1218, NBRK=1219, HAVE_RET=1220
```

**关键**：`st/cs/ck/...` 仍是同名变量（只是变成视图），所以**语句循环体语义不变**；
`sts/css` 原来用 `slice(st,0,16)`/`slice(cs,0,16)`，已改为 `st`/`cs` 本身
（`slice()` 只接受 Array，`slice_at()` 才接受 Slice；两处声明删除后，全部 `sts`/`css`
引用做机械改名，共 644 处）。

  偏移表集中在 `main` 的声明处；
- 80 个输入（73 个 `bootstrap/bls/tests/*.ls` + 7 个 `bootstrap/src/*.ls`）用 seed 解释器
  跑改前/改后：**79 个 `rc`/SHA-256/stderr 完全一致**，仅 `names_stage` 自编译产物变化
  （`87da4cdb…a5df` → `cda1c789…f966`，大小 393682 → 394580 字节）；
- `bash bootstrap/ci/run-interp.sh` 全绿；
- `QEMU_TIMEOUT=2400 bash bootstrap/ci/run-qemu.sh`：`PASS compiled slice_at stage1 -> exit 88`、
  `PASS fixed point: stage2 == stage3`，新固定点 **`e545a9e8…bf869`**，`QEMU-GUEST: RESULT=PASS`。

### B0.3b-2（完成）：真正抽函数

```lean
fn emit_body(mem: Slice[U8], ps: Slice[Int], n: Int) -> Int
```

**ABI 修正**：B-LS 的参数上限是 **6 个参数槽**，每个 `Slice` 占 2 个槽（base+len）。
原计划的 `emit_body(ctxi, code, data, src, ps, n)` 实际是 11 个槽，seed 会报
`too many argument slots`。最终签名压缩到 5 个槽：

- `mem`：把 `src`/`code`/`data` 合并成一个 `membuf[1376256]` 后的 `Slice[U8]`；
  函数内用 `slice_at(mem, 0, n)`、`slice_at(mem, 262144, 1048576)`、
  `slice_at(mem, 1310720, 65536)` 恢复 `srcs/c/ds`；
- `ps`：`post` 的 `Slice[Int]`；`ctxi = slice_at(ps, 137952, 2048)` 从 `post` 尾部的
  保留区恢复 Int 状态（原 `ctxa` 数组已去掉）。`post` 扩到 140000 ints；
- `n`：源长度。

函数体内：

- `ctxi` 视图恢复 `st/cs/ck/...`（偏移见 `main` 声明处）；
- 标量改成 `ctxi[NF]` / `ctxi[DLEN]` / `ctxi[CD]` / `ctxi[NBRK]`
  （`dlen` 109 处、`nf` 68 处、`cd` 56 处、`nbrk` 8 处）；
- `post[...]` → `ps[...]`（21 处），`data[...]` → `ds[...]`（1 处）；
- `have_ret` 是每个函数体局部的临时量（在 body 循环内 `let have_ret = 0`），
  不需要跨函数，因此保持局部，不占 `HAVE_RET` 槽。

`main` 在调用前写 `ctxi[NF]`/`ctxi[DLEN]`，调用后读回并恢复 `nf`/`dlen`；
`st[6]`/`cs`/`fname`/`flabel` 通过 `ctxi` 视图自动可见。返回错误码 0/4。

实现与验收（2026-10-22）：

- 搬移后的循环体与 B0.3b-1 原文逐行一致，仅做上述 `post/data/nf/dlen/cd/nbrk`
  机械替换（脚本比对：1578 行完全匹配）；
- 80 个输入用 seed 解释器跑改前/改后：**79 个 `rc`/SHA-256/stderr/stdout 完全一致**，
  仅 `names_stage` 自编译产物变化（`87da4cdb…a5df` → `1dc967a6…f501`，
  393682 → 399393 字节）；
- `bash bootstrap/ci/run-interp.sh` 全绿；
- QEMU 全量：`PASS compiled slice_at stage1 -> exit 88`、`PASS fixed point: stage2 == stage3`，
  新固定点 **`b9a21c38…bbb7d`**，`QEMU-GUEST: RESULT=PASS`。
