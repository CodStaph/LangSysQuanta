# B0.3b 拆解 · 抽 `emit_body`（纯搬家，行为不变）

> 状态：**拆解完成（2026-10-22），未实现**。B0.3a（`slice_at`，seed + stage1）已完成并 QEMU 验证；

## 1. 循环的真实依赖（实测）

`main` 内 `while 1 { … }`（约 1,001 行）依赖：

| 类别 | 项 | 数量/用法 |
|---|---|---|
| `Slice[U8]` | `c`(code)、`ds`(data)、`srcs`(source) | 每语句都用 |
| `Slice[Int]` | `ps`(post, 131072)、`st`(16)、`cs`(16) | 高频 |
| 控制/补丁数组 | `ck/cje/cstart/bloop/bpos/rname/fname/flabel/fret/fret_t1/fret_t2/fret_ty/fparams/fpelem` | 共 ~1,232 ints |
| 标量 | `dlen`(87 处)、`cd`(56)、`nf`(32)、`nbrk`(8)、`have_ret`(2) | **必须能跨函数读写** |

参数预算（≤6）：`ctxi(Int)`、`code(U8)`、`data(U8)`、`src(U8)`、`ps(Int)`、`n` = **6**，
所以标量必须放进 `ctxi`。

## 2. 两步走

### B0.3b-1（安全、可独立验证）：把 Int 状态打包成一个 `ctx` 数组 + 视图

在 `main` 里：

```lean
let ctx: Array[Int, 2048] = Array.zeroed();
let st: Slice[Int]      = slice_at(ctx, 0, 16);
let cs: Slice[Int]      = slice_at(ctx, 16, 16);
let ck: Slice[Int]      = slice_at(ctx, 32, 64);
let cje: Slice[Int]     = slice_at(ctx, 96, 64);
let cstart: Slice[Int]  = slice_at(ctx, 160, 64);
let bloop: Slice[Int]   = slice_at(ctx, 224, 64);
let bpos: Slice[Int]    = slice_at(ctx, 288, 64);
let rname: Slice[Int]   = slice_at(ctx, 352, 64);
let fname: Slice[Int]   = slice_at(ctx, 416, 128);
let flabel: Slice[Int]  = slice_at(ctx, 544, 128);
let fparams: Slice[Int] = slice_at(ctx, 672, 16);
let fpelem: Slice[Int]  = slice_at(ctx, 688, 16);
let fret: Slice[Int]    = slice_at(ctx, 704, 128);
let fret_t1: Slice[Int] = slice_at(ctx, 832, 128);
let fret_t2: Slice[Int] = slice_at(ctx, 960, 128);
let fret_ty: Slice[Int] = slice_at(ctx, 1088, 128);
// 标量槽：NF=1216, DLEN=1217, CD=1218, NBRK=1219, HAVE_RET=1220
```

**关键**：`st/cs/ck/...` 仍是同名变量（只是变成视图），所以**循环体一行不用改**；
`sts/css` 原来用 `slice(st,0,16)`/`slice(cs,0,16)`，改为 `st`/`cs` 本身（`slice()` 只接受 Array）。
验收同 B0.3a：78 输入逐字节不变 + QEMU 固定点（新哈希）。

### B0.3b-2（下一步）：真正抽函数

```lean
fn emit_body(ctxi: Slice[Int], code: Slice[U8], data: Slice[U8],
             src: Slice[U8], ps: Slice[Int], n: Int) -> Int
```

- 函数体内用 `slice_at(ctxi, OFF, LEN)` 恢复 `st/cs/ck/...`；
- 标量改成 `ctxi[NF]` / `ctxi[DLEN]` / `ctxi[CD]` / `ctxi[NBRK]` / `ctxi[HAVE_RET]`
  （循环内共 **~185 处**：`dlen` 87、`cd` 56、`nf` 32、`nbrk` 8、`have_ret` 2）；
- `main` 在调用前后用 `ctxi[...]` 读写这些槽（`dlen` 必须带回，因为后面要写 ELF 头/数据段）；
- 返回错误码 0/4；`main` 再按 `ctxi[DLEN]` 继续。

## 4. 风险

| 风险 | 缓解 |
|---|---|
