## 1. surface

```ls
struct S[A, B] { f0: A, f1: B, f2: Int }

fn main() -> Int {
    let p: S[Int, Str];   // 实例化：S[Int, Str] -> 实例 ii
    p.f0 = 11;            // 泛型参数位字段写（装箱 8 字节槽）
    p.f2 = 22;            // 具体 Int 字段写
    if p.f0 != 11 { return 1; }   // 字段读
    let q: S[Str, Int];
    q.f2 = 33;
    if q.f2 != 33 { return 3; }
    return 7;
}
```

- 参数列表 `[A, B]`：最多 **2**（沿用 B4 `scan_generic_list`）；
- 字段类型：**位置参数**（`A`/`B`，登记 100/101）或具体 `Int/U8/Str`（1/2/3）；
- 字段上限 **4**（模板表宽 12 的内部约束，与 B4 enum 变体上限一致）；
- 同名 struct/enum 禁止（沿用全局名字约束）。

## 2. 编译期实现

### 2.1 表复用（零新增顶层函数）

`MAX_FUNCS=128` 在 B7 已满，R2.2 **不新增任何顶层函数**：

| B4 泛型 enum 概念 | R2.2 复用为 struct 概念 |
|---|---|
| `tmpl` 表 `post[123000]`（宽 12：`{name,nparams,nvar,4×{vname,pty}}`） | struct 模板（一个名字一行，字段占“变体”槽） |
| `tmpl_add(nm, nparams)` / `tmpl_var_add(ti,f,pty)` | 声明 struct 泛型头 + 逐字段登记 |
| `inst` 表 `post[124000]`；`mk_inst(ti,t1,t2)` | 实例化：pty 100→t1、101→t2，具体 1/2/3 直存 |
| `tmpl_find` / `inst_var_find` / `inst_var_pty` / `inst_nvariants` | 名字解析 / 字段名查找 / 字段类型 / 字段数 |

**`nparams` bit 7（`| 128`）区分 struct 模板与 enum 模板**（该槽此前无人读，
可安全挪用）：struct 声明侧写入 `gc | 128`（真实参数数 `gc & 127`）；
`parse_user_desc` 发现该位即 `st[0]=save; return 0`，把 `S[Int,Str]` 让回
typed-let 的 struct 分派，不再被 enum 描述路径 (`8|(ii<<8)`) 抢走。

关键判分顺序（`emit_body` typed-let 与 `parse_ty`）：先做 `is_sgen`
（`tmpl_find(ps,tnm) ≥ 0` 且 `ps[123001+ti*12+1] & 128`）→ 泛型实例分支；
否则 `st_find≥0` → B7 非泛型 struct 行（`scan_funcs` 会把 struct 名预登记进
`st` 表，即使它是泛型的——非泛型优先试探会撞上，bit 试探必须在前）。

### 2.2 类型码与变量登记

| 项 | 码 |
|---|---|
| 泛型 struct 实例类型 | `120 + ii`（enum 实例是 `8\|(ii<<8)`，互不重叠） |
| `sv` 变量 sidx | `70 + ii`（B7 0..69 为非泛型行） |
| 裸 struct 值类型 | `30 + sidx`；`sidx≥70` 时改发 `120+ii` |
| 实例大小 | `inst_nvariants(ps, ii) * 8`（每字段 8 字节槽） |

### 2.3 字段写与读

- 写（`p.f = e;`）：`fi = inst_var_find(ps, ii, f)`；
  `off = (sv 基址 & ~31bit) + fi*8`；parse 实参后校验
  `post[110000+栈顶] == inst_var_pty(ps, ii, fi)`（100/101 已被 `mk_inst`
  具体化为 t1/t2），恒发 8 字节 store（`48 89 05`），`fix-it` 无；
  不匹配 → `struct: field type mismatch`。
- 读（表达式 `p.f`）：`push_post(12, off)`（8 字节槽 load），类型按 Int；
  泛型字段与非泛型分离点在 `sv_find` 的 sidx `≥70` 判定。
- `struct_payload_expr`（用裸 struct 值做算术）继续 `E-LS-UNSUPPORTED`
  ——本轮曾因裸值类型码漏 `30+` 前缀回归过一次，修复即恢复拒绝。

## 5. 已知边界（沿 B-LS 既有）

- 字段类型 Str 字面量存（`p.f0 = "ab"`）：不支持——非泛型 struct 同边界
  （拒绝：`struct: bad field value`）；
- 泛型 struct 作函数实参/整体比较：未开放（B7 impl 也不接管泛型实例）；
- `>2` 类型参数、`>4` 字段：`E-LS-UNSUPPORTED` / `scan_generic_list` 拒绝；
- 守卫 18600 上新自编译占用 ~18400，余 ~200——下一轮（预计 R2.5 系列）需第
  四次扩容或回归 compact。
