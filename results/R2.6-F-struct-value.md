## 2. 实现（`bootstrap/src/names_stage.ls`，全部内联）

| 路径 | 改动 |
|---|---|
| 参数类型校验（签名扫描） | `vmode != 2` 的普通 struct 不再直接拒绝；改做 `st_size` 的 8 字节对齐检查（新消息 `struct value parameters need an 8-byte-aligned layout`） |
| 参数入帧分支 | `fval==2 || pe==0 || pe>=100` 扩为再收 `pe∈[30,100)`；结构体复制条件 `fval==2 || pe>=120` 扩为 `fval==2 || pe∈[30,100) || pe>=120`（**不得**用 `pe>=30`——泛型参数 `T` 取 `100+gi`，会被误判为 struct） |
| 单寄存器 store | 条件改为 `pe < 30 || (pe >= 100 && pe < 120)`：struct（30..99 与 120+）由复制序言负责，不再多写一次指针值 |
| 返回类型解析 | `-> Name` 先 `st_find` 命中普通 struct → `fdesc = 30+si`，附带对齐检查与 `is_gen` 拒绝；否则回退 `parse_user_desc`（泛型 enum） |
| 调用方接收 | `let r = f()` 的 `rkind` 分支由 `>=120` 扩为 `>=120 || [30,100)`；普通 struct 用 `st_size` 与 sidx `rty-30` 建 `sv`，随后从 rax 逐字拷入 |
| 裸名解析（parse_expr） | var 表项类型为 0 且同名 `sv` 存在时优先走 `sv`（按值 struct 参数同时在两表登记，var 侧类型留 0），否则裸名会被当成标量 load |

## 5. 结论与边界

- **结论**：普通 struct 的按值 ABI 与泛型实例一致：**调用方传地址（一个参数槽），
  callee 复制到本帧**；返回值放 rax（本帧地址）。QEMU 全量含新用例运行时断言与固定点。
- **边界 1**：返回值地址属于 callee 帧，仅在 `let r = f();` 紧随调用拷出时有效；`g(f())`、`f().x` 等嵌套用法未验证（与 R2.6-A 泛型返回值同一边界）。
- **边界 2**：struct 参数（ref 或按值）仍各占一个参数槽，最多四个；第五个起拒绝。
- **边界 3**：复制按 8 字节字进行，非 8 字节对齐布局拒绝。
