## 1. 背景：R2.2 已实现

- R2.2（2026-10-31）让泛型 struct `struct S[A, B] { f0: A, f1: B, f2: Int }` 可通过
  typed-let 实例化（`let p: S[Int, Str]`）+ 字段读写，但**不能作函数实参/返回值/整体比较**。
- 泛型 struct 复用 B4 的 `tmpl`/`inst` 表：模板行 nparams `bit7` 标记 struct；
  实例类型码 `120+ii`；sv 变量 sidx `70+ii`（与 B7 非泛型 `30+si` 区分）。

## 2. 本项改动（`bootstrap/src/names_stage.ls`，全部内联）

| 路径 | 改动 |
|---|---|
| **A1 参数类型解析**（`scan_funcs`/`emit_body` 签名扫描的 `else` 分支） | `name_id` 后先 `tmpl_find`，若命中泛型 struct 模板（bit7）→ 解析 `[t1,t2]` → `mk_inst` → `pe = 120+ii`；否则回退原 B7 `st_find` → `30+si` |
| **Slice 判断收紧**（`Str`/`Slice` 分支） | 参数与 struct 字段类型解析处，把 `Slice` 分支首字母 `S` 条件收紧为完整 `Slice` 单词，避免 `S[Int,Str]` 被误当 Slice/Str |
| **A2. 参数校验放行**（`vmode==2` ref 分支） | `(pe>=30 && pe<100) || pe>=120` 均视为 struct；泛型实例用 `inst_nvariants*8` 校验 8 对齐 |
| **A2. 非 ref 泛型参数放行**（8019 后） | 泛型实例（pe>=120）允许非 ref 按值传递（普通 B7 struct 仍强制 ref） |
| **callee 序言拷贝** | 泛型 struct 参数（ref 或值）分配 `inst_nvariants*8` 字节、`sv_add(sidx=70+ii)`、从参数寄存器逐字段拷贝；额外寄存器 store 对 `pe>=120` 跳过（拷贝已处理） |
| **A3. 返回类型解析**（签名 `-> S[...]`） | 返回类型处探测泛型 struct 模板 → `mk_inst` → `fdesc = 120+ii`（`parse_user_desc` 会拒泛型 struct，须在之前探测） |
